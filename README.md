### MSc thesis: predicting water pipe failures

I predicted which water pipes are most likely to fail within 1, 3, 5 and 10 years, using discrete-time survival analysis on data from three Danish water utilities, combined with climate data from DMI, soil data from GEUS and road data from GeoDanmark. I compared an interpretable logistic regression model with Random Forest and XGBoost, and used SHAP to explain the predictions. It was the first pipe failure model for Danish utilities to use soil data for individual pipes.

Most of the work was in the data: each utility recorded its data differently, some pipe ages were impossible, and many failures were dated 1 January because failures over the Christmas holidays were registered afterwards.

*The thesis used proprietary utility data, so the code isn't public here.*
